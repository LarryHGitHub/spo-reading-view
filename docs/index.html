SPO Reading View – Privacy Policy

Last updated: 2026-11-26

Summary

SPO Reading View does not collect, transmit, sell or share any personal data or usage data.

What the extension does

When you open a Word or Excel document hosted on SharePoint Online or OneDrive for work or school (*.sharepoint.com, *.sharepoint.cn), the extension asks the browser to rewrite the document URL so that it opens in Reading View instead of Editing View. The rewrite is performed locally by the browser's built-in declarativeNetRequest API using static rules packaged with the extension.

Data handling

  • The extension's code does not read page content, documents, cookies, credentials or browsing history.
  • The only data stored is two on/off preferences, saved locally on your device with chrome.storage.local. They are never sent anywhere.
  • The extension makes no network requests of its own, has no analytics, no advertising and no remote code.

Permissions

  • declarativeNetRequestWithHostAccess + host access to *.sharepoint.com / *.sharepoint.cn: required to rewrite document URLs on those sites only.
  • storage: saves your two on/off preferences locally.

Third parties

No data is shared with any third party. This extension is an independent project and is not affiliated with, endorsed by, or sponsored by Microsoft.
