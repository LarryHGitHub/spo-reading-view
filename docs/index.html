SPO Reading View – Privacy Policy

Last updated: YYYY-MM-DD · applies to version 2.3.0 and later

Summary

SPO Reading View does not collect, store, transmit, sell or share any personal data or usage data. It has no servers of its own, no analytics and no advertising.

What the extension does

It makes Word and Excel documents in SharePoint Online and OneDrive for work or school (*.sharepoint.com, *.sharepoint.cn) open in Reading View instead of Editing View:

  1. Document links (/_layouts/15/Doc.aspx): the browser rewrites the URL locally using static declarativeNetRequest rules packaged with the extension.
  2. Sharing links (for example /:w:/s/… or /:x:/s/…): a content script running only on those pages sends one request to the same SharePoint site the user is already visiting, using the user's existing browser session, to look up which document the link points to. It then opens that document's standard Doc.aspx address, which step 1 turns into Reading View. The lookup result is used immediately and is not stored or sent anywhere else.

Data handling

  • The extension does not read document content, page text, cookies, passwords or browsing history.
  • No data leaves the user's browser except the single lookup request described above, which goes only to the SharePoint host the user is visiting.
  • Stored data: four on/off preferences in chrome.storage.local; a short-lived list of documents already switched to Reading View in each tab (chrome.storage.session, cleared when the tab or browser closes); and a per-tab marker in the page's sessionStorage that prevents redirect loops. None of this is transmitted.
  • No remote code is loaded or executed.

Permissions

  • declarativeNetRequestWithHostAccess: rewrite SharePoint document URLs to Reading View.
  • webRequest: observe (not block or modify) navigations to SharePoint sharing links.
  • storage: save the on/off preferences locally.
  • Host access to *.sharepoint.com and *.sharepoint.cn only.

Third parties

No data is shared with any third party. This extension is an independent project and is not affiliated with, endorsed by, or sponsored by Microsoft.
